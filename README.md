# Smart To-Do + Reminder System
A simple Python program to manage daily tasks and remind you at the set time. 
Tasks are saved in CSV and reminders show in terminal.
## Features
- Add tasks with name and time
- View all tasks
- Background reminder at the specified time
- Tasks are saved in a CSV file
## How to Run
1. Make sure Python is installed
2. Open terminal in project folder
3. Run the program:
4. Add tasks and keep terminal open to receive reminders
